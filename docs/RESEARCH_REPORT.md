# 금 가격 회귀 모델 — 조사 및 개발 보고서

## 1. 프로젝트 개요

**목표**: 금의 가치를 결정하는 5가지 핵심 경제 지표를 활용하여 금 가격 회귀 모델을 구축하고, 그 결과를 GitHub Pages 사이트로 시각화하여 공개한다.

**지표 선정 근거**:
- 실질 금리, 달러 가치, 중앙은행 매수세, 채굴 원가는 금 가격의 4대 핵심 동인으로 널리 인정됨
- 유가(WTI)는 달러로 결제되는 대표 원자재이며, 에너지 비용이 채굴 원가에 직접 영향을 주므로 5번째 지표로 추가

## 2. 데이터 소스 조사

### 2.1 조사한 무료 데이터 소스

| 지표 | 후보 소스 | 최종 선택 | 선택 이유 |
|------|-----------|-----------|-----------|
| **금 가격** | FRED (`GOLDAMGBD228NLBM`), yfinance (GLD ETF), Free Gold API | **FRED** | 수십 년 역사 데이터, 안정적 API, London Fixing 기준가 |
| **실질 금리** | FRED (`DFII10`, `REAINTRATREARAT10Y`), 10Y Treasury - CPI 직접 계산 | **FRED `DFII10`** | 10년 물가연동채(TIPS) 수익률로 시장이 반영한 실질 금리를 직접 제공 |
| **달러 지수** | FRED (`DTWEXBGS`), Yahoo Finance (`DX-Y.NYB`), ICE DXY | **FRED `DTWEXBGS`** | 무역가중 광의 달러 지수, 2006년부터 제공. yfinance는 폴백 옵션으로 보존 |
| **중앙은행 매수** | World Gold Council (Goldhub), IMF IFS | **수동 CSV** (WGC 분기 보고서) | 무료 API 없음. WGC가 분기별 보도자료로 발표하는 순매수량(톤)을 수작업 정리 |
| **채굴 원가 (AISC)** | WGC/Metals Focus 연간 보고서, GDX ETF (프록시) | **수동 CSV** + GDX 프록시(선택) | AISC 시계열 API 없음. 연간 산업 평균 AISC를 수작업 정리. GDX는 실시간 프록시로 보완 가능 |
| **유가 (WTI)** | FRED (`DCOILWTICO`, `DCOILBRENTEU`), Datahub.io, yfinance | **FRED `DCOILWTICO`** | WTI 일일 가격, 수십 년 역사, FRED 통합으로 일관성 확보 |

### 2.2 API 키 요구사항

- **FRED API**: 무료 등록 후 API 키 발급 필요 (`FRED_API_KEY` 환경변수)
- **yfinance**: API 키 불필요 (Yahoo Finance 스크래핑 기반)
- **WGC/AISC**: API 없음 → 수동 데이터 수집

### 2.3 데이터 한계점 발견

조사 과정에서 발견한 핵심 제약사항:

1. **중앙은행 매수 데이터**: 분기별로만 발표됨 (월간/일간 데이터 없음)
2. **AISC 데이터**: 연간으로만 발표됨 (가장 낮은 빈도)
3. **데이터 빈도 불일치**: 일간(시장 데이터) vs 분기(CB) vs 연간(AISC) → 월간으로 통일 필요
4. **FRED 달러 지수(`DTWEXBGS`)**: 2006년부터만 제공 → 분석 시작점을 2010년으로 설정

## 3. 모델링 접근법 조사

### 3.1 선행 연구 검토

금 가격 예측에 사용되는 주요 모델링 기법을 조사한 결과:

| 모델 | 장점 | 단점 | 성능 (문헌 기준) |
|------|------|------|------------------|
| **선형 회귀 (OLS)** | 해석 용이, 계수 부호로 경제적 관계 검증 | 비선형 관계 포착 불가 | 베이스라인 |
| **Ridge/Lasso** | 다중공선성 처리, 과적합 방지 | 여전히 선형 | OLS 대비 소폭 개선 |
| **Random Forest** | 비선형 포착, 해석 가능 | 앙상블 특성상 외삽 약함 | 양호 |
| **XGBoost / LightGBM** | 최고 성능 (MAE 27% 감소 보고) | C++ 의존성, 블랙박스 | 최고 |
| **SVR** | 고차원에 강함 | 하이퍼파라미터 민감 | 보통 |
| **LSTM / 딥러닝** | 시계열 패턴 학습 | 150개 데이터로 과적합 위험 큼 | 부적합 |

### 3.2 최종 모델 선정

**3가지 모델 계층 구조**를 채택:

1. **OLS (선형 회귀)**: 각 지표의 계수 부호(+/-)로 경제 이론과의 정합성을 검증하는 해석용 모델
2. **Ridge 회귀**: 달러 지수↔유가 간 다중공선성을 L2 정규화로 처리
3. **Gradient Boosting**: 비선형 관계 포착을 위한 성능 최적 모델

**XGBoost/LightGBM 미채택 사유**: 
- scikit-learn 내장 `GradientBoostingRegressor`로 충분 (~150행, 5-6개 피처)
- 추가 C++ 컴파일 의존성 회피
- 데이터 규모 대비 과적합 위험 동일

**딥러닝 미채택 사유**:
- 150개 월간 데이터포인트로는 LSTM 등의 학습이 불가능
- 해석 가능성이 중요한 프로젝트 목적에 부적합

### 3.3 피처 엔지니어링 결정

| 결정 사항 | 선택 | 근거 |
|-----------|------|------|
| 데이터 빈도 | **월간 (monthly)** | 일간·분기·연간 데이터의 실용적 교차점 |
| 리샘플링 방식 | 월말 마지막 영업일 | 금융 데이터 관례 |
| 저빈도 데이터 처리 | 전방 채움 (forward-fill) | 분기/연간 → 월간 보간 시 가장 보수적인 방법 |
| 파생 피처 | `gold_oil_ratio` (금/유가 비율) | 달러 가치 변동을 상쇄한 상대 가치 지표 |
| Train/Test 분할 | 시간 기반 (마지막 18개월 = Test) | 시계열 데이터의 미래 유출(data leakage) 방지 |
| 스케일링 | StandardScaler | 선형 모델 계수 비교를 위한 표준화 |

## 4. 기술 아키텍처 결정

### 4.1 프로젝트 구조

```
gold_price/
├── data/                     # 수동 CSV + 캐시된 원시 데이터
├── src/
│   ├── fetch_data.py         # 데이터 수집 (FRED API + 폴백)
│   ├── prepare_data.py       # 전처리 + 피처 엔지니어링
│   ├── model.py              # 3개 모델 학습/평가
│   └── charts.py             # 시각화 PNG 생성
├── docs/                     # GitHub Pages (정적 HTML)
│   ├── index.html
│   ├── style.css
│   └── images/               # 생성된 차트
└── run_pipeline.py           # 파이프라인 오케스트레이터
```

### 4.2 핵심 설계 결정

| 결정 | 선택 | 대안 검토 | 거부 사유 |
|------|------|-----------|-----------|
| 웹 프레임워크 | 정적 HTML + CSS | React, Jekyll | 빌드 없이 GitHub Pages 즉시 배포 가능 |
| ML 라이브러리 | scikit-learn만 | XGBoost, TensorFlow | 150행 데이터에 과도, 의존성 최소화 |
| 시각화 | matplotlib + seaborn | Plotly, D3.js | 정적 PNG 생성이 목적, 인터랙티브 불필요 |
| API 폴백 | 샘플 데이터 자동 생성 | 에러 발생 후 종료 | API 키 없이도 데모 실행 가능 |
| 데이터 캐싱 | `data/raw/` CSV 캐시 | SQLite, pickle | 단순하고 디버깅 용이 |

### 4.3 의존성


## 5. 실행 결과

### 5.1 데이터셋

- **기간**: 2010년 12월 ~ 2025년 12월 (181개월)
- **피처**: `real_rate`, `usd_index`, `wti_oil`, `cb_purchases`, `aisc`, `gold_oil_ratio`
- **Train**: 163개월 / **Test**: 18개월

### 5.2 모델 성능 (샘플 데이터 기준)

| 모델 | RMSE | MAE | R² |
|------|------|-----|-----|
| OLS (선형 회귀) | 272.70 | 216.11 | -43.65 |
| Ridge 회귀 | 206.99 | 175.49 | -24.73 |
| Gradient Boosting | 188.10 | 128.87 | -20.24 |

> ⚠️ **주의**: 위 결과는 API 키 없이 생성한 합성(synthetic) 샘플 데이터 기준입니다.
> 샘플 데이터는 실제 경제적 관계가 내재되어 있지 않으므로 음수 R²는 예상된 결과입니다.
> FRED API 키를 설정하고 실제 경제 데이터로 재실행하면 의미 있는 결과를 얻을 수 있습니다.

## 6. 향후 개선 방향

| 영역 | 개선안 | 기대 효과 |
|------|--------|-----------|
| 데이터 | FRED API 키로 실제 데이터 적용 | 실질적인 모델 성능 평가 가능 |
| 데이터 | 중앙은행 매수 월간 데이터 확보 | 피처 해상도 향상 |
| 모델 | XGBoost/LightGBM 추가 비교 | 잠재적 성능 향상 |
| 피처 | 시차(lag) 변수 추가 (t-1, t-3) | 선행 지표 효과 반영 |
| 피처 | VIX (변동성 지수) 추가 | 위험 선호도 반영 |
| 피처 | ETF 자금 유입량 (GLD, IAU) | 투자 수요 반영 |
| 평가 | 시계열 교차검증 (TimeSeriesSplit) | 과적합 진단 강화 |
| 평가 | 정상성 검정 (ADF test) | 수준(level) vs 수익률(returns) 판단 |
| 웹사이트 | Plotly 인터랙티브 차트 | 사용자 탐색 경험 향상 |

## 7. 결론

본 프로젝트는 금 가격의 5대 핵심 동인을 체계적으로 조사하고, 각 지표의 최적 데이터 소스를 선정하여 다중 회귀 모델을 구축했습니다.

**핵심 발견사항**:
- 무료로 사용 가능한 시계열 데이터는 FRED API가 가장 포괄적이고 신뢰성 높음
- 중앙은행 매수와 AISC는 무료 API가 부재하여 수작업 정리가 불가피
- 데이터 빈도 불일치(일간/분기/연간)는 월간 리샘플링 + 전방 채움으로 해결
- 약 150개 데이터포인트로는 복잡한 모델(딥러닝)보다 전통적 ML 모델이 적합
- Gradient Boosting이 비선형 관계 포착에서 가장 유리하나, OLS의 해석 가능성도 핵심 가치

파이프라인은 `python run_pipeline.py` 한 줄로 전체 과정(데이터 수집 → 전처리 → 학습 → 평가 → 시각화)을 자동 실행하며, GitHub Pages를 통해 결과를 즉시 공유할 수 있도록 설계되었습니다.
